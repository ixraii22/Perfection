# خطوة عمياء

تطبيق ويب بصفحة واحدة (بدون خوادم أو تبعيات) لكسر حاجز الكمالية والتسويف، عبر إجبار البداية بأقل وأسوأ شكل ممكن بدل التخطيط المثالي الذي لا يبدأ أبدًا.

## الميزات

- **مؤقت 5 دقائق**: كتابة مهمة والعمل عليها لمدة 5 دقائق فقط، بشكل غير مثالي إن لزم الأمر.
- **تفريغ الأفكار**: مساحة كتابة حرة تُمسح تلقائيًا بعد 10 دقائق لمنع التفكير الزائد وإعادة الصياغة.
- **إنجاز اليوم**: تسجيل مهام صغيرة أُنجزت دون تقييم جودة.
- **الاختيار العشوائي**: عند التردد بين عدة مهام، يختار التطبيق واحدة عشوائيًا ويبدأ المؤقت فورًا.
- **لوحة الإنجازات**: ملخص أسبوعي (أيام نشطة، ستريك حالي وأطول ستريك) مع رسالة تحفيزية، ومعرض لإنجاز عشوائي من الماضي.
- **إعادة صياغة الأفكار السلبية**: ثلاثة أسئلة سريعة لكسر التفكير الزائد، تنتهي بربط خطوة عملية بمؤقت 5 دقائق.
- **التذكيرات**: إشعارات متصفح قابلة للتخصيص بعدة أوقات يومية.
- **سجل الوقت**: بعد كل مؤقت، يمكن تسجيل الوقت الفعلي المستغرق عبر ساعة تفاعلية، مع تصنيف تلقائي للفئات (قراءة، رياضة، كتابة، وغيرها) وعرض إجمالي الساعات لكل فئة.

جميع البيانات (الستريك، الإنجازات، سجل الوقت) تُحفظ محليًا في متصفحك عبر `localStorage`، ولا تُرسل لأي خادم.

## التشغيل

لا حاجة لأي تثبيت. افتح ملف `index.html` مباشرة في أي متصفح حديث.

## النشر عبر GitHub Pages

1. ارفع محتويات هذا المجلد إلى مستودع على GitHub.
2. من إعدادات المستودع (Settings → Pages)، فعّل GitHub Pages على فرع `main` والمجلد الجذري.
3. سيصبح التطبيق متاحًا على رابط من نوع `https://<username>.github.io/<repo-name>/`.
